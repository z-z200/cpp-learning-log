## C++ 知识点

### `std::vector<std::string>`

动态数组，用来保存多条待办事项：

```cpp
std::vector<std::string> todos;
```

### `push_back`

向列表末尾添加元素：

```cpp
todos.push_back(todo);
```

### `getline`

读取包含空格的一整行文本：

```cpp
std::getline(std::cin, todo);
```

使用 `std::cin >> todo` 会在空格处停止，因此菜单选项读取后需要先执行：

```cpp
std::cin.ignore();
```

清理输入缓冲区中的回车符。

### `do...while`

让菜单至少显示一次，并在用户没有选择退出时继续循环：

```cpp
do {
    // 菜单逻辑
} while (choice != 0);
```

### 遍历列表

```cpp
for (std::size_t i = 0; i < todos.size(); ++i) {
    std::cout << i + 1 << ". " << todos[i] << "\n";
}
```

```powershell

git pull

```

编译：

```powershell
g++ .\src\cli_todo.cpp -o .\build\cli_todo.exe
```

运行：

```powershell

```

提交：

```powershell

```

推送功能分支：

```powershell

```

合并后同步：

```powershell
git switch main
git pull --prune
git branch -d feature/cli-todo-v01
```

## 遇到的问题

推送 GitHub 时曾超时。原因是本机 `hosts` 将 GitHub 域名解析到 `127.0.0.1`，同时 Steam++ 加速器在本地 443 端口运行，但其转发或证书状态异常。

处理方法：

- 刷新 DNS 缓存：`ipconfig /flushdns`
- 重新开启或修复 Steam++ 的网络加速
- 使用 `git ls-remote origin` 验证连接

网络恢复后，`git add`、`git commit` 和 `git push` 均成功。
